# Portfólio interativo — guia rápido

Se você viu uma tela **"Not Found"**, verifique se está abrindo o arquivo correto.
Este projeto é um site estático e depende do `index.html` na raiz.

## Como visualizar

### Opção 1: abrir o arquivo diretamente

Abra `index.html` no navegador.

### Opção 2: servidor local simples

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura esperada

- `index.html`
- `styles.css`
- `script.js`

Se estiver utilizando algum preview automático, certifique-se de que ele aponta para a raiz do projeto.
